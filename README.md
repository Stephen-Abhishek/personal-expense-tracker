# Personal Expense Tracker

A simple financial dashboard built using Python and Streamlit to help users track monthly income, expenses, and savings.

## Features

- Enter monthly income.
- Add expenses by category.
- View expense history.
- Delete individual expenses.
- Calculate total expenses and remaining savings.
- Calculate savings percentage.
- Visualize savings progress.
- Download expense records as a CSV file.

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib

## Installation and Setup

1. Clone or download this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`

4. Open the local URL displayed in your terminal.

## Project Purpose

This project demonstrates beginner-level Python programming, data handling, calculations, and interactive dashboard development.
